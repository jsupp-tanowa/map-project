version: 1.2.2
release_date: 2026-09-04
summary: ズームボタン有効化など

changes:
  - app.js: zoomControl: false → zoomControl: true に変更。Google Maps標準のズーム＋／ーボタンが右下に表示されます。
style.css: .button-area を right: 10px → left: 10px に変更（bottom: 85px は維持）。現在地ボタン・再読み込みボタンが左下に移動し、標準ズームボタン（右下）と重ならなくなります。
style.css: .gm-bundled-control, .gm-svpc { display:none !important; } から .gm-bundled-control を除外し、.gm-svpc { display:none !important; } のみ残しました。これによりズームボタンは表示されつつ、ストリートビューのペグマンは引き続き非表示のままです。

renderListView() のリスト項目クリック処理に、お気に入りタブと同じ map.setCenter() + map.setZoom(15) を追加しました。

item.marker は既にマーカーオブジェクトそのものを保持しているので（お気に入り側のように名前でマーカーを検索し直す必要がなく）、item.marker.getPosition() でそのまま中心座標を取得できます。

リストを閉じる
該当ピン位置へ setCenter + ズームレベル15へ setZoom
マーカーのclickイベントをトリガーしてカードを開く

  - 本番環境（Firebase Hosting）へのデプロイ
  - 今後の機能追加は dev ブランチで行い、main に merge して反映
